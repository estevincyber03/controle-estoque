# Controle de Estoque · Wyntech

Sistema web mobile-first para contagem física e auditoria de inventário da Wyntech, otimizado para iPhone e Android via **GitHub Pages**.

## Recursos
- **575 itens** distribuídos em **12 depósitos** com fotos integradas
- **Salvamento automático** no navegador (`localStorage` + `IndexedDB`)
- **PWA Offline**: pode ser adicionado à Tela de Início do iPhone/Android e funciona mesmo sem internet no estoque
- **Exportação Excel (`.xlsx`)**: inventário completo ou somente divergências
- **Importação de planilhas**: `.xlsx`, `.xls` ou `.csv`
